/* Ammo Making: Reloading Press (add-on) - the press recipes.

   EXPERIMENTAL, NOT YET SEEN IN GAME.

   THE BODY OF THIS FILE IS GENERATED from AC_Calibres.lua of the main mod
   (AC_Calibres.buildPressRecipes) by tests/write_recipes.lua; this comment
   is kept. Do not edit the body.

   One recipe for each case, projectile and assembly step of every calibre,
   made from the hand recipe of the same step:

     Tags = AmmoMakingReloadingPress   only the Reloading Press entity of
                                       this add-on offers it (its CraftBench
                                       Recipes tag); the hand-craft window
                                       does not list it
     timedAction = UseHandPress        vanilla's press action (PressClayBrick)
     time                              60 % of the hand recipe's, rounded down
     inputs                            the hand recipe's, with the SAME
                                       calibre's die set kept, and without
                                       the hammer line: the press does the
                                       pressing
     outputs, OnCreate                 the hand recipe's: same count, same
                                       XP, same quality roll

   The pattern is vanilla's own press and mold: a station tag and a kept
   tool that decides what comes out
   (entities/pottery/cratRecipes/craftrecipe_handpress.txt, 42.20.4).

   The OnCreate functions are defined by the main mod when this add-on is
   active (AC_Materials.lua builds one per recipe of its list, and the
   press recipes join that list through the feature "reloadingPress"). */
