/* Ammo Making - recipes on the vanilla Build 42 stations.

   Every block is adapted from a vanilla 42.20.4 recipe.

   Metallurgy, from entities/blacksmith/craftRecipes/recipes_blacksmith_furnaces_i.txt:

     AmmoMaking_SmeltZincOre     <- SmeltCopperOre (same fields, zinc items)
     AmmoMaking_Cast*Ingot       <- CastIronIngot (tongs + mold kept, Furnace tag) with the
                                    kept empty crucible of ExtractIronFromSmallItem
     AmmoMaking_CastBrassIngots  <- same casting block, two metals in

   Case stock, from recipes_blacksmith_other_metals.txt and recipes_improvised_weapons.txt:

     AmmoMaking_ForgeSmallBrassSheets <- Forge_Copper_Sheet (tools, flags, timed action)
     AmmoMaking_PunchBrassCaseCups    <- cold work on a surface: the punch line of the
                                         scrap-armour recipes, the hammer line and timed
                                         action of NailSpikeWeapon

   Geology equipment, from AC_Materials.EQUIPMENT_RECIPES:

     AmmoMaking_Assemble*AssayKit           <- the mod's own surface block (Making); every
                                               line a vanilla item by id, nothing kept
     AmmoMaking_BuildLaboratoryAssayAnalyzer <- MakeImprovisedFlashlight (recipes_electrical.txt):
                                               MakingElectrical, category Electrical, the kept
                                               screwdriver line with flags[Prop1]

   Ammunition components, generated from AC_Calibres.lua:

     AmmoMaking_MixGunpowder          <- hand work of GatherGunpowder, mortar line of
                                         MakeAerosolBomb; charcoal + fertilizer in
     AmmoMaking_Make*PrimersFrom*     <- the cup-punching block; toy caps or match heads
     AmmoMaking_ForgeDieSet<calibre>  <- Forge_Small_Metalworking_Punch_Set
     AmmoMaking_FormCase<calibre>,
     AmmoMaking_SwageBullets<calibre> <- cold work with the calibre's die set kept
     AmmoMaking_AssembleRound<calibre> -> the VANILLA round item, one per craft

   A 12 gauge shell is a calibre like the others: its "case" is the brass hull,
   its "bullet" the shot charge. Its assembly takes one more line, the wad,
   written as vanilla writes a consumed rag (recipes_blacksmith_blades.txt:
   "item 1 [Base.RippedSheets;...] mode:destroy").

   A drainable input counts uses: "item 1 [Base.GunPowder]" is one use of a jar.

   THE BODY OF THIS FILE IS GENERATED. Change AC_Materials.lua / AC_Calibres.lua
   and run tests/write_recipes.lua; this comment is kept.

   Brass recycling, generated from AC_Recycling.lua:

     AmmoMaking_ScrapBrass<units>        <- the cold hammer block of the cup recipe; unwanted
                                            cups, sheets, cases and hulls in, vanilla
                                            Base.BrassScrap out, half the brass lost, no XP
     AmmoMaking_CastBrassIngotFromScrap  <- the casting block, ten brass scrap in

   The recipes live in module Base, like every vanilla recipe, so the engine
   handles them exactly as its own; the AmmoMaking_ prefix keeps the ids
   unique. Station attachment is the Tags line only; the furnaces and forges
   have no lit or fuel state, charcoal is an input.

   No SkillRequired / xpAward lines: the Ammo Making perk is registered from
   Lua after scripts are parsed, so the engine would drop them. AC_Materials
   attaches the skill requirement at boot and awards XP from OnCreate.

   AC_Materials.RECIPES mirrors this file; tests/run_tests.lua fails when
   the two differ. */
